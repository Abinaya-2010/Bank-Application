# Bank-Application
A simple console-based Banking System written in Python. It supports Savings Bank (SB) and Fixed Deposit (FD) accounts, and provides basic operations like deposit, withdrawal, interest calculation, and account closure.


Features
- Create SB and FD accounts
- Deposit and Withdraw from SB accounts
- Calculate interest monthly (SB: 4%, FD: 8.25%)
- Auto-generated customer ID system
- Simple and user-friendly text interface
